# RiftPulse Quest adapter

Initial native Scotland2/Quest bootstrap for Beat Saber 1.40.8. This development build verifies native loader startup and logs a clear status. Pairing, in-game UI, realtime events, Chat, and BSR behavior are not implemented in this bootstrap yet.

Dependencies are QPM-managed (Scotland2, beatsaber-hook, paper). Build from this directory using the configured Android NDK and CMake/Ninja. Output artifact intended for testing is the QMOD package.
