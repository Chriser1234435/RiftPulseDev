# RiftPulse PCVR adapter

Initial installable BSIPA bootstrap for the pinned Beat Saber 1.40.8 instance. This build verifies plugin loading and writes lifecycle logs. Pairing, UI, realtime events, Chat, and BSR behavior are not implemented in this bootstrap yet.

Build: `dotnet build RiftPulse.Pcvr.csproj -c Release`

Target framework: .NET Framework 4.7.2. Loader reference is pinned to the installed Beat Saber 1.40.8 instance.
