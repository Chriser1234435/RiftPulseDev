RiftPulse Quest Standalone 0.3.13 Alpha
Beat Saber 1.40.8 (Quest standalone)

INSTALL:
1. Confirm Beat Saber on the Meta Quest headset is the standalone Quest version 1.40.8.
2. Download RiftPulse-Quest-0.3.13-Alpha.qmod from https://app.riftpulse.me.
3. Connect the Quest to ModsBeforeFriday (MBF), import the downloaded QMOD, and install it.
4. Launch Beat Saber and open RiftPulse from the Mods panel.
5. Pair the headset to your RiftPulse account using the five-digit code shown in-game.

SONG REQUESTS:
- Viewers can send !bsr followed by a BeatSaver map key or map URL in connected Twitch, YouTube, or TikTok chat.
- The website dashboard shows validated requests and lets the streamer start, complete, or remove entries.
- Use REFRESH SONG QUEUE in the Quest Song Requests card to read the current queue. The in-game menu shows up to three queue entries.

FLOATING CHAT PANEL:
- The panel is world-space and remains movable with its VR drag handle.
- Chat stays bottom-aligned: newest messages appear at the bottom and oldest messages are removed from the top.
- X/Y/Z position, width, and height settings persist across restarts until changed again. Re-center restores the centered/front position.

Quest Standalone only. This is a QMOD package; there is no Quest ZIP. Do not install it in the PCVR Plugins folder.

Build verification: native ARM64 compilation and QMOD package validation succeeded. Physical Quest menu rendering, queue refresh, pairing, and live provider behavior still need headset confirmation.
