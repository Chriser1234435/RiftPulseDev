RiftPulse Quest Standalone 0.3.15 Alpha

Beat Saber 1.40.8 / Meta Quest Standalone

Install:
1. Confirm standalone Beat Saber 1.40.8 is installed on the headset.
2. Connect the Quest to ModsBeforeFriday (MBF).
3. Import `RiftPulse-Quest-0.3.15-Alpha.qmod` in MBF and install it.
4. Launch Beat Saber and open RiftPulse from the Mods panel.

In game:
- Pair the headset through the five-digit code generated by the mod.
- Enable Chat and Song Requests in the RiftPulse menu.
- Chat and BSR each have a floating world-space panel with a white controller grab handle.
- BSR settings include X/Y/Z placement, width, and height; the selected size is retained after re-centering.
- Select a BSR request and choose YES to install the map to SongCore CustomLevels or NO to remove the request.
- Chat shows timestamp, platform-color square, sender, and message with highlighted stream-event labels.

This is a Quest Standalone QMOD. Do not install it in PCVR.
