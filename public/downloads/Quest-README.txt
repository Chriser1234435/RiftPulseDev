RiftPulse Quest Standalone 0.3.14 Alpha
Beat Saber 1.40.8 (Quest standalone)

INSTALL:
1. Confirm Beat Saber on the Meta Quest headset is the standalone Quest version 1.40.8.
2. Download RiftPulse-Quest-0.3.14-Alpha.qmod from https://app.riftpulse.me.
3. Connect the Quest to ModsBeforeFriday (MBF), import the QMOD, and install it.
4. Launch Beat Saber and open RiftPulse from the Mods panel.
5. Pair the headset to your RiftPulse account using the five-digit code shown in-game.

BSR SONG REQUESTS:
- Configure the viewer command, requester cooldown (0–3600 seconds), and queue size (1–50) from Configure BSR inside RiftPulse.
- Viewers can send the command plus a BeatSaver map key or BeatSaver map URL in connected Twitch, YouTube, or TikTok chat.
- Open Request Queue to view the queue in a separate movable world-space panel. Scroll the request list and select a song to see its requester and provider.
- Choose YES / DOWNLOAD to install the map into SongCore CustomLevels, or NO / REMOVE to reject and remove the request.
- Grab the panel handle to move it; use Re-center Request Panel to reset it. Quest saves the moved position across restarts.
- After a successful download, open Solo > Custom Levels and select the song. The mod does not auto-start a map.

FLOATING CHAT PANEL:
- The chat feed remains world-space and movable with its VR grab handle.
- New messages sit at the bottom; oldest messages leave from the top.
- Chat position and display settings persist across restarts.

Quest Standalone only. This is a QMOD package; there is no Quest ZIP. Do not install it in the PCVR Plugins folder.

Build verification: Native ARM64 compilation and QMOD structure validation passed. Physical Quest installation, panel rendering/dragging, map import, and Custom Levels indexing still need headset confirmation.
