RiftPulse Quest alpha 0.1.16
Beat Saber 1.40.8 standalone (Scotland2)

The QMOD explicitly selects the Scotland2 modloader and declares the project-resolved Beat Saber Hook, BSML, Custom Types, and Paper2 dependencies. Its root mod.json is UTF-8 JSON without a BOM.

MBF import and headset runtime loading still require confirmation on the Quest headset. This is a UI preview: Chat/BSR toggles are local-only; the pairing button produces a local test code and is not connected to the website/API. Authentication, persisted settings, live chat, viewer aggregation, and BSR are not implemented in this preview.
