RiftPulse Quest Standalone 0.1.51 Alpha
Beat Saber 1.40.8 (Quest standalone)

INSTALL:
1. Make sure Beat Saber on your Meta Quest headset is the standalone Quest version 1.40.8.
2. Download RiftPulse-Quest-0.1.51-Alpha.qmod from the RiftPulse development Downloads page.
3. Connect the Quest to ModsBeforeFriday (MBF), import the downloaded QMOD, and install it with MBF.
4. Launch Beat Saber on the Quest headset and open RiftPulse from the Mods panel.
5. Pair using the five-digit code and app.riftpulse.me. Select MOVE CHAT PANEL TO VIEW to create/reposition the world-space panel. Select CONFIGURE CHAT PANEL to open its settings popup. X/Y/Z adjust placement; width/height adjust panel geometry. Changes save automatically.

RIFTPULSE MENU:
- Quest now follows the PCVR pairing, Chat, and BSR card hierarchy with matching labels and descriptions.
- Pairing code is shown separately from GENERATE PAIRING CODE.
- Chat settings use the same metre units and panel width/height ranges as PCVR.

FLOATING CHAT PANEL:
- A world-space floating panel in Beat Saber menus and gameplay, not a HUD overlay.
- The panel preserves its current facing when settings change; a headset-relative rotation offset is saved for reopening.
- Grab the visible DRAG TO MOVE bar with a VR controller to move the panel.
- Incoming messages appear at the bottom; oldest messages are trimmed from the top.
- A small blue marker appears immediately before the sender's display name.
- Twitch display names are purple (#9146FF), YouTube red (#FF0000), and TikTok white (#FFFFFF).
- Display names are preferred over account handles when supplied by the provider.
- Recent messages/events and combined viewer totals appear when fresh data is available.
- If the panel says DEVICE LINK REQUIRED, generate a fresh code and pair the headset again.

This QMOD is for Quest Standalone only. Do not install it into the PCVR Beat Saber Plugins folder.
Alpha note: QMOD import and real-headset runtime validation are still required. Confirm the menu card layout, settings persistence, panel-facing behavior, handle movement, and live provider feed on the headset.
