# RiftPulse Quest adapter - alpha 0.1.24`r`n`r`nNative ARM64 Scotland2 client for Beat Saber 1.40.8 (1.40.8_7379). Generates a five-digit pairing code, registers the pairing challenge with the RiftPulse API, checks website claim status, and after linking loads and saves Chat and BSR module preferences.`r`n`r`nFix in 0.1.24: Replaced Quest UnityWebRequest header and upload-handler requests with managed System.Net.Http.HttpClient JSON requests. Pairing challenge registration sends JSON in a POST body, avoiding Unity rejected custom headers. Device-authenticated module settings and toggle operations use a standard Bearer Authorization header. Request completion is marshalled to Unity main-thread context; module preference load/toggle operations are serialized.`r`n`r`nThe QMOD manifest is UTF-8 without BOM and begins directly with {, for QuestPatcher/MBF import. Pairing status is checked manually using CHECK PAIRING STATUS after entering the code on https://app.riftpulse.me.`r`n`r`nThis is an alpha candidate. Headset import, menu layout, pairing and preference-save runtime validation remain for testers. Module switches persist preferences only; live provider chat/events, combined viewer counts, ChatIntegrations command execution, and BSR song-request fulfillment are not yet implemented.
