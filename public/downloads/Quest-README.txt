RiftPulse Quest Standalone 0.1.48 Alpha
Beat Saber 1.40.8 (Quest standalone)

INSTALL:
1. Make sure Beat Saber on your Meta Quest headset is the standalone Quest version 1.40.8.
2. Download RiftPulse-Quest-0.1.48-Alpha.qmod from app.riftpulse.me.
3. Connect the Quest to ModsBeforeFriday (MBF), import the downloaded QMOD, and install it with MBF.
4. Launch Beat Saber on the Quest headset and open RiftPulse from the Mods panel.
5. Pair using the five-digit code and app.riftpulse.me. Select OPEN 3D CHAT PANEL to create the movable world-space panel. Select CUSTOMIZE CHAT PANEL inside RiftPulse to open the panel settings popup. X/Y/Z adjust placement; width/height adjust panel geometry and scale chat text with the panel. Changes save automatically. If the panel says DEVICE LINK REQUIRED, generate a fresh code and pair the headset again.

FLOATING CHAT PANEL:
- A world-space floating panel in Beat Saber menus and gameplay, not a HUD overlay.
- The chat feed uses the full panel body with a compact LIVE CHAT heading.
- Grab the visible white DRAG TO MOVE bar with a VR controller to move the panel.
- Position and size preferences are saved in Quest app storage.
- Use OPEN 3D CHAT PANEL again to reset its position in front of your current view.
- Chat text scales with the panel when its width or height changes.
- The in-game feed uses the same newest 100 chat/event records as the website Events/Chat view, ordered into chronological display.
- Recent Twitch, YouTube, and TikTok LIVE messages/events and combined viewer totals appear when fresh data is available.

This QMOD is for Quest Standalone only. Do not install it into the PCVR Beat Saber Plugins folder.

Alpha note: QMOD import and real-headset runtime validation are still required. Confirm the nested settings popup, panel placement, handle movement, saved position, and live provider feed on the headset. ChatIntegrations command execution and BSR song-request fulfillment are separate workstreams.
