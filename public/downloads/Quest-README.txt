RiftPulse Quest Standalone 0.1.38
Beat Saber 1.40.8 (Quest standalone)

INSTALL:
1. Make sure Beat Saber on your Meta Quest headset is the standalone Quest version 1.40.8.
2. Download RiftPulse.Quest.qmod from app.riftpulse.me.
3. Connect the Quest to ModsBeforeFriday (MBF), import the downloaded QMOD, and install it with MBF.
4. Launch Beat Saber on the Quest headset and open RiftPulse from the Mods panel.
5. Pair using the five-digit code and app.riftpulse.me. Open the RiftPulse menu and select OPEN 3D CHAT PANEL. The movable panel remains available in menus and gameplay. If the panel says DEVICE LINK REQUIRED, generate a fresh code and pair the headset again. Select CHAT PANEL SETTINGS to adjust X/Y/Z position, width, and height with sliders and arrow buttons.

FLOATING CHAT PANEL:
- A world-space floating panel in Beat Saber menus and gameplay, not a HUD overlay.
- The chat feed uses the full panel body with a compact LIVE CHAT heading.
- Grab the visible white DRAG TO MOVE bar with a VR controller to move the panel.
- Position and size preferences are saved in Quest app storage. Use CHAT PANEL SETTINGS in the RiftPulse menu to customize X/Y/Z position, width, and height.
- Use OPEN 3D CHAT PANEL again to reset its position in front of your current view.
- The chat feed is a TextMeshPro UI child on the floating screen's world-space canvas.
- Recent Twitch, YouTube, and TikTok LIVE messages/events and combined viewer totals appear when fresh data is available.

This QMOD is for Quest Standalone only. Do not install it into the PCVR Beat Saber Plugins folder.

Alpha note: QMOD import and real-headset runtime validation are still required. Confirm panel placement, handle movement, saved position, and live provider feed on the headset. ChatIntegrations command execution and BSR song-request fulfillment are separate workstreams.
