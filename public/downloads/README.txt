- Download: https://app.riftpulse.me/downloads/RiftPulse.Pcvr-0.3.6.zip

Quest Standalone:
- Download RiftPulse-Quest-0.3.13-Alpha.qmod for Meta Quest / Beat Saber standalone 1.40.8.
- Import and install the QMOD with ModsBeforeFriday (MBF).
- The Quest package is a QMOD only; there is no Quest ZIP.
- Quest 0.3.13 includes the account-backed song-request queue view and a single refresh control in the Song Requests card.
- Download: https://app.riftpulse.me/downloads/RiftPulse-Quest-0.3.13-Alpha.qmod

Song requests:
- Viewers can use !bsr [BeatSaver key or URL] in connected chat.
- The website queue validates BeatSaver maps and gives the streamer Start, Complete, and Remove controls.
- Requester cooldown and maximum queue size are configurable from RiftPulse settings.
