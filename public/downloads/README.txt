RiftPulse PCVR 0.1.18
Beat Saber PCVR 1.40.8
The PCVR ZIP contains only Plugins/RiftPulse.Pcvr.dll and README.txt. The BSIPA manifest is embedded in the DLL. Extract the ZIP directly into the Beat Saber PCVR game folder. Remove an old RiftPulse Plugins/manifest.json file from an earlier package if one exists; do not place a loose manifest inside Plugins.
Pairing uses https://app.riftpulse.me. Pair this installation before syncing module preferences. Live Chat and BSR are not implemented yet.
