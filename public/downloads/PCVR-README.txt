RiftPulse PCVR 0.3.6
Windows / Beat Saber PCVR 1.40.8

INSTALL:
1. Download RiftPulse.Pcvr-0.3.6.zip.
2. Extract the ZIP directly into your Beat Saber PCVR 1.40.8 game folder (the folder containing Beat Saber.exe). Keep the folder structure from the ZIP.
3. Confirm the file is at: Beat Saber game folder\Plugins\RiftPulse.Pcvr.dll.
4. Do not add a separate manifest.json in Plugins. The BSIPA manifest is embedded in RiftPulse.Pcvr.dll.
5. Launch Beat Saber PCVR 1.40.8 and open RiftPulse from the Mods panel.
6. Pair the mod to your RiftPulse account with the five-digit code.

SONG REQUESTS:
- Viewers can send !bsr followed by a BeatSaver map key or map URL in connected Twitch, YouTube, or TikTok chat.
- The account queue validates map details and shows accepted requests in the website dashboard.
- Use the in-game REFRESH SONG QUEUE button to view the three next/playing entries.
- Start, complete, and remove requests from the website Song Queue panel.

LIVE CHAT:
- The floating chat feed remains bottom-aligned: new messages appear at the bottom and older messages leave from the top.
- Provider colors and sender markers distinguish Twitch, YouTube, and TikTok messages and events.
- The panel stays separate from the song-request queue.

PCVR only. Do not install this ZIP into Quest Standalone.

Build verification: PCVR DLL build and package validation succeeded. Confirm queue rendering and live platform requests during a Beat Saber headset session.
