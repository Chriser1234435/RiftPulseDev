RiftPulse PCVR 0.1.40
Windows / Beat Saber PCVR 1.40.8

INSTALL:
1. Download RiftPulse.Pcvr-0.1.40.zip.
2. Extract the ZIP directly into your Beat Saber PCVR 1.40.8 game folder (the folder containing Beat Saber.exe). Keep the folder structure from the ZIP.
3. Confirm the file is at: Beat Saber game folder\Plugins\RiftPulse.Pcvr.dll
4. Do NOT copy or create a separate manifest.json in the Plugins folder. The BSIPA manifest is embedded in RiftPulse.Pcvr.dll.
5. If an earlier RiftPulse package was installed, remove the old RiftPulse Plugins\manifest.json file if present. It is a duplicate, loose manifest and prevents BSIPA from discovering the plugin class correctly.
6. Launch Beat Saber PCVR 1.40.8, open RiftPulse from the Mods panel, and pair this installation with your RiftPulse account.
7. The compact world-space LIVE CHAT panel stays available in menus and gameplay. Grab the visible white DRAG TO MOVE bar with a VR controller to move it; placement is saved locally. Choose CONFIGURE CHAT PANEL inside the RiftPulse mod menu to adjust X/Y/Z position and panel width/height with draggable sliders or arrow buttons. Use MOVE CHAT PANEL TO VIEW to reset its position.

The in-game panel now uses the same newest 100 chat/event records as the website Events/Chat view, rather than returning stale rows from an older ascending LIMIT query. Text size remains compensated when panel width or height changes, and the panel front faces the headset. Recent Twitch, YouTube, and TikTok LIVE messages/events and the combined viewer total appear when fresh data is available. If the panel says DEVICE LINK REQUIRED, generate a new pairing code in the RiftPulse Mods menu and enter it on app.riftpulse.me. Real-headset validation is still required.

This DLL is for PCVR only. Do not install it into Quest Standalone.
