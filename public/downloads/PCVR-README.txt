RiftPulse PCVR 0.1.32
Windows / Beat Saber PCVR 1.40.8

INSTALL:
1. Download RiftPulse.Pcvr.zip.
2. Extract the ZIP directly into your Beat Saber PCVR 1.40.8 game folder (the folder containing Beat Saber.exe). Keep the folder structure from the ZIP.
3. Confirm the file is at: Beat Saber game folder\Plugins\RiftPulse.Pcvr.dll
4. Do NOT copy or create a separate manifest.json in the Plugins folder. The BSIPA manifest is embedded in RiftPulse.Pcvr.dll.
5. If an earlier RiftPulse package was installed, remove the old RiftPulse Plugins\manifest.json file if present. It is a duplicate, loose manifest and prevents BSIPA from discovering the plugin class correctly.
6. Launch Beat Saber PCVR 1.40.8, open RiftPulse from the Mods panel, and pair this installation with your RiftPulse account.
7. The compact world-space LIVE CHAT panel stays available in menus and gameplay. Grab the visible white DRAG TO MOVE bar with a VR controller to move it; placement is saved locally. Choose CUSTOMIZE CHAT PANEL in the RiftPulse menu to adjust X/Y/Z position, width, and height with sliders and arrow buttons. Use MOVE CHAT PANEL TO VIEW to reset its position.

The live chat panel displays recent Twitch, YouTube, and TikTok LIVE messages and the combined viewer total when fresh data is available. The visible white grab bar remains the controller drag target. If the panel says DEVICE LINK REQUIRED, generate a new pairing code in the RiftPulse Mods menu and enter it on app.riftpulse.me. This alpha compiled cleanly, but real-headset validation is still required.

This DLL is for PCVR only. Do not install it into Quest Standalone.
