PCVR pairing integration for Beat Saber 1.40.8. Mod creates a five-digit code and registers it against the RiftPulse development API. A stable installation credential is generated as 32 random bytes and protected locally with Windows DPAPI CurrentUser; backend stores a SHA-256 digest and assigns it to the device after website claim. Pairing status poll is wired. Secure WebSocket bearer authentication has code in the Railway API development branch but is awaiting deployment and validation. Chat, BSR, and settings sync are not implemented. Runtime load and in-game UI verification are pending.
