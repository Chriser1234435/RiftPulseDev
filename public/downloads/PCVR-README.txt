PCVR pairing integration build for Beat Saber 1.40.8. BSIPA main-menu button and BSML pairing screen. The mod generates a five-digit code, registers it through the RiftPulse development API, and polls pairing status for website claim. Pairing shows success when the API reports claimed. Secure per-device credential authentication and realtime chat/BSR still remain to be implemented; in-game runtime visual/load verification pending.
