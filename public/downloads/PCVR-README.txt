RiftPulse PCVR 0.3.1
Windows / Beat Saber PCVR 1.40.8

INSTALL:
1. Download RiftPulse.Pcvr-0.3.1.zip.
2. Extract the ZIP directly into your Beat Saber PCVR 1.40.8 game folder (the folder containing Beat Saber.exe). Keep the folder structure from the ZIP.
3. Confirm the file is at: Beat Saber game folder\Plugins\RiftPulse.Pcvr.dll
4. Do NOT copy or create a separate manifest.json in the Plugins folder. The BSIPA manifest is embedded in RiftPulse.Pcvr.dll.
5. If an earlier RiftPulse package was installed, remove the old RiftPulse Plugins\manifest.json file if present.
6. Launch Beat Saber PCVR 1.40.8 and open RiftPulse from the Mods panel.
7. Use OPEN DISPLAY LAB to adjust X/Y/Z position, width, and height. Use RE-CENTER CHAT PANEL to reset the display to a centered, front-facing position in front of your headset.

LIVE CHAT:
- The RiftPulse title and combined viewer count stay pinned at the top of the panel.
- Incoming chat messages are bottom-aligned: newest messages appear at the bottom and older messages are removed from the top.
- Chat text is more legible, and its feed no longer pushes the title down when the panel is mostly empty.
- A small blue marker appears immediately before the sender's display name.
- Twitch display names are purple (#9146FF), YouTube red (#FF0000), and TikTok white (#FFFFFF).
- The panel uses the platform display name rather than the account handle where the provider supplies one.
- Recent messages/events and combined viewer totals appear when fresh data is available.
- If the panel says DEVICE LINK REQUIRED, generate a new pairing code in the RiftPulse Mods menu and enter it on app.riftpulse.me.

MENU:
- The Nexus visual design is retained.
- Device Link and Spatial Display are grouped in the left column; Live Chat and Song Requests are grouped in the right column to prevent card overlap.
- A restored account connection is shown as LINKED rather than an empty row of dashes.

This DLL and ZIP are for PCVR only. Do not install them into Quest Standalone.

Runtime note: build, package, and local installation checks passed. Confirm the floating panel and menu in a live Beat Saber PCVR headset session.
