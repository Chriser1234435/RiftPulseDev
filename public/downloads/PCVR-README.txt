RiftPulse PCVR 0.1.44
Windows / Beat Saber PCVR 1.40.8

INSTALL:
1. Download RiftPulse.Pcvr-0.1.44.zip.
2. Extract the ZIP directly into your Beat Saber PCVR 1.40.8 game folder (the folder containing Beat Saber.exe). Keep the folder structure from the ZIP.
3. Confirm the file is at: Beat Saber game folder\Plugins\RiftPulse.Pcvr.dll
4. Do NOT copy or create a separate manifest.json in the Plugins folder. The BSIPA manifest is embedded in RiftPulse.Pcvr.dll.
5. If an earlier RiftPulse package was installed, remove the old RiftPulse Plugins\manifest.json file if present.
6. Launch Beat Saber PCVR 1.40.8, open RiftPulse from the Mods panel, and pair this installation with your RiftPulse account.
7. Use CONFIGURE CHAT PANEL to adjust X/Y/Z position, width, and height. Settings changes preserve the panel's current facing; headset-relative position and rotation offset are saved. Use MOVE CHAT PANEL TO VIEW to reset its placement in front of your view.

LIVE CHAT:
- Incoming messages appear at the bottom; oldest messages are trimmed from the top.
- A small blue marker appears immediately before the sender's display name.
- Twitch display names are purple (#9146FF), YouTube red (#FF0000), and TikTok white (#FFFFFF).
- The panel uses the platform display name rather than the account handle where the provider supplies one.
- Recent messages/events and combined viewer totals appear when fresh data is available.
- If the panel says DEVICE LINK REQUIRED, generate a new pairing code in the RiftPulse Mods menu and enter it on app.riftpulse.me.

This DLL is for PCVR only. Do not install it into Quest Standalone.
